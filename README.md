## 🧠 How I think about product

1. **Split work by risk.** Let AI handle the fuzzy parts and deterministic code handle the consequential ones.
2. **Fail closed.** When unsure, escalate to a human instead of guessing.
3. **Evals are release gates.** Safety metrics must hit zero before anything ships.
4. **Bound every retry loop.** Reliability is a product feature.
5. **Make everything observable.** If you can't trace it, you can't trust it.
