## 🧠 How I build products

1. **Split work by risk.** AI handles the fuzzy parts; deterministic code handles the consequential ones.
2. **Fail closed.** When unsure, escalate to a human.
3. **Evals are release gates.** Safety metrics must hit zero before shipping.
4. **Bound every retry loop.** Reliability is a feature.
5. **Make it observable.** If you can't trace it, you can't trust it.
